# Production_BLS_RAG_App
To deploy on Streamlit Cloud so that anyone can use it

It is hosted on Streamlit Cloud
<img width="837" height="405" alt="image" src="https://github.com/user-attachments/assets/bd4258ba-e836-457c-83d0-3a4dd1cca6c6" />

Description - It is for answering any question from 50 pdfs which is around 25000 pages,the pdfs contain data related to Occupation, what are the most popular one, How much money one can earn, how much people are needed in one sector, What skills one need to get a job from the year 1950-2013


Link for the App - https://appuctionblsragapp-jr6whfvegkspxwewg43vyd.streamlit.app


1. LLM used - llama-3.3-70b-versatile from GROQ

2. Embedding Model - jina-embeddings-v3 from JINA

3. Vector Database - Pinecode


- All embeddings are stored in Pinecode, Vector Database.
- LLM running from GROQ API
- Embedding model also running from JINA API
